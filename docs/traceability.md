# Traceability matrix

This matrix links each claim about PetHub to the code that implements it and the check that supports it.
Paths in the Implementation and Verification columns are relative to `devtools/` unless they start with `docs/`
or `README`. The architecture behind them is in [architecture.md](architecture.md).

## Legend

| Status                                                   | Meaning                                                                                                                                                                        |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Verified by automated tests                              | A test or script in the repository exercises the behaviour in the acceptance criteria (the command is in the Verification column). Re-run the command to reproduce the result. |
| Verified by automated tests + manual check by the author | Same, and the author also checked it by hand. No row has this status yet: the author adds it per row after their own check.                                                    |
| Implemented, not verified end to end                     | The code exists, but no automated test covers the whole criterion (or none covers it at all). Rows also say which part is covered, if any.                                     |

Test commands (run in `devtools/`):

| Kind        | Command                          | Needs                                                                                                                                 |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Unit        | `npm test`                       | Nothing else (no database).                                                                                                           |
| Integration | `npm run test:integration`       | PostgreSQL with the migrations applied and `DATABASE_URL` set; files that sign in need the `SEED_*` variables.                        |
| End to end  | `npm run test:e2e`               | A running app at `PLAYWRIGHT_BASE_URL` (default `http://127.0.0.1:3000`), the same database, `SEED_*` variables, Playwright browsers. |
| Smoke       | `sh infra/scripts/smoke-demo.sh` | A running demo stack ([README](../README.md#quick-start-in-the-course-container)).                                                    |
